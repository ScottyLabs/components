---
title: ScottyLabs Components
description: Design tokens and components for ScottyLabs projects, available for React and Svelte.
---

The ScottyLabs component library is the design system used across ScottyLabs projects. It includes:

- Design tokens (colors, typography, spacing, radii, shadows) generated from a single Figma source, available as CSS custom properties and TypeScript constants.
- React components built on [Radix UI](https://www.radix-ui.com/) primitives.
- Svelte components built on [Bits UI](https://www.bits-ui.com/) primitives.
- A shared public API: the same prop names and semantics in both frameworks.

Install instructions, theming guidance, and the token reference are in the sidebar. The interactive component browser is at [Components](https://storybook.scottylabs.org).
