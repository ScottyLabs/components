---
title: Install
description: Install the ScottyLabs component library in a React or Svelte project.
---

## React

```sh
deno add npm:@scottylabs/react npm:@scottylabs/tokens npm:@scottylabs/styles
```

```tsx
import "@scottylabs/styles";
import { Button } from "@scottylabs/react";
```

## Svelte

```sh
deno add npm:@scottylabs/svelte npm:@scottylabs/tokens npm:@scottylabs/styles
```

```svelte
<script>
  import "@scottylabs/styles";
  import { Button } from "@scottylabs/svelte";
</script>

<Button>Click</Button>
```
