---
title: Install
description: Install the ScottyLabs component library in a React or Svelte project.
---

## React

```sh
bun add @scottylabs/react @scottylabs/tokens @scottylabs/styles
```

```tsx
import "@scottylabs/styles";
import { Button } from "@scottylabs/react";
```

## Svelte

```sh
bun add @scottylabs/svelte @scottylabs/tokens @scottylabs/styles
```

```svelte
<script>
  import "@scottylabs/styles";
  import { Button } from "@scottylabs/svelte";
</script>

<Button>Click</Button>
```
