# @scottylabs/storybook-react

This app is the React Storybook for the design system. It loads stories from `packages/react/src/**/*.stories.*` and `src/**/*.stories.*`.

It is composed into `@scottylabs/storybook` via that app's `refs` configuration, and story `title`s of the form `Components/<Name>` group adjacent to their Svelte counterparts in the composed view.
