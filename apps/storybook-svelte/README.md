# @scottylabs/storybook-svelte

This app is the Svelte Storybook for the design system. It loads stories from `packages/svelte/src/**/*.stories.*` and `src/**/*.stories.*`.

It is composed into `@scottylabs/storybook` via that app's `refs` configuration, and story `title`s of the form `Components/<Name>` group adjacent to their React counterparts in the composed view.
